# AgentShield — درع الوكلاء

**بوابة أمان لوكلاء الذكاء الاصطناعي (AI Agent Security Gateway)** — مشروع تخرج.

تقف البوابة بين وكلاء الذكاء الاصطناعي والأنظمة الحقيقية (قواعد البيانات، الملفات، البريد، الواجهات الخارجية)، وتعترض كل طلب أداة وتفحصه قبل التنفيذ:

- **الهوية المزدوجة:** رمز المستخدم وشهادة الوكيل معاً
- **سياسات الصلاحيات المبنية على السمات (ABAC):** سماح، رفض، أو موافقة بشرية
- **كشف حقن الأوامر:** تواقيع معروفة + تشابه دلالي + فك الترميز المخفي
- **منع تسريب البيانات (DLP):** إخفاء المفاتيح السرية والبيانات الشخصية والنصوص عالية الإنتروبيا
- **درجة خطورة مركبة:** ما يتجاوز الحد (0.70) أو العمليات التدميرية يتوقف بانتظار موافقة المسؤول
- **سجل تدقيق موقّع ومتسلسل** يكشف أي تلاعب، و**زر إيقاف طارئ** شامل أو لأداة بعينها

كل القرارات حتمية ولا تعتمد على أي نموذج لغوي.

## محتويات المستودع

| المسار | الوصف |
|---|---|
| `Documentation-2.pdf` | وثيقة المشروع (الفصول 1–3) |
| `frontend/` | لوحة تحكم المسؤول (Next.js + React + Tailwind)، عربي/إنجليزي، فاتح/داكن |
| `frontend/src/lib/engine/` | محرك الفحص: السياسات، الحقن، التسريب، الخطورة، ومسار القرار |
| `frontend/test/` | اختبار حزمة الهجمات (16 حالة) على المحرك |

> حالياً تعمل اللوحة على بيئة مؤسسة تجريبية محلياً، والخادم (FastAPI + PostgreSQL + Redis) هو المرحلة القادمة.

## التشغيل

```bash
cd frontend
npm install
npm run dev     # http://localhost:3000
npm test        # اختبار حزمة الهجمات
```
